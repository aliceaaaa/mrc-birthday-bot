# MRC Birthday Bot

Телеграм-бот напоминани1 о др

---

## Возможности

* Хранит дни рождения по `@username`
* Можно добавить в любой чат
* Напоминания:
  * за 7 дней
  * за 1 день
  * в день рождения

* За 7 дней спрашивает подарок у именинника в личке
* После выбора подарка выбор публикуется в чат

---

## Требования

* Python 3.10+
* Токен
* Зависимости:
  * aiogram
  * aiosqlite
  * apscheduler

---

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install aiogram aiosqlite apscheduler
```

---

## Настройка
### Токен

Файл `config.py`:

```python
BOT_TOKEN = "ТОКЕН ИЗ BOTFATHER"
```

---

## База данных

* SQLite
* Файл: `birthdays.db`
* Создаётся автоматически

---

## Импорт данных

```bash
python import_birthdays.py
```

---

## Запуск

```bash
python bot.py
```

---

## Использование в чате

### Добавление бота

1. Добавь бота в чат
2. Задать ему др
3. Чат сохранится автоматически

---

### Добавление дня рождения

```
/add @username DD.MM
```

Пример:

```
/add @alisandrii 31.10
```

---

## Проверка

### Напоминания

* Поставь дату:
  * сегодня
  * завтра
  * через 7 дней
* В 10:00 бот пришлёт сообщение

---

### Подарки

1. Именинник получает сообщение с кнопками
2. Выбирает подарок
3. Кнопки исчезают
4. В чат приходит сообщение:

```
@username выбрал подарок: Деньги
```

## Ограничения

* Требуется `@username`
* Без username бот не может писать про выбор подарка
* Бот не управляет участниками чата, если он не админ
