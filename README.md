# MRC Birthday Bot

Телеграм-бот, который напоминает группе о днях рождения.

---

## Возможности

* Хранит дни рождения по `@username`; добавляют их админы
* Напоминает в группе в 9:00 (Тбилиси):
  * за 7 дней
  * за 1 день
  * в день рождения
* В напоминании есть кнопки выбора подарка (🎁 Вышивка / 💸 Деньги).
  Видят их все, но нажать может только именинник. После выбора кнопки
  исчезают, а в группу приходит сообщение «@username хочет в подарок: …».
  Подарок выбирается заново каждый год.
* Если бот перезапустился после 9:00, а напоминаний сегодня ещё не было, он пришлёт их сразу после старта

---

## Команды

Для всех:

| Команда | Что делает |
|---|---|
| `/month` | ДР в этом месяце |
| `/when @username` | когда ДР у человека |
| `/upcoming` | ДР в ближайшие 30 дней |
| `/start`, `/help` | список команд |

Только для админов (`@alisandrii`, `@firasakhapova`, список в `config.py`):

| Команда | Что делает |
|---|---|
| `/add @username DD.MM` | добавить или изменить ДР |
| `/remove @username` | удалить ДР |
| `/test` | тестовое сообщение со списком ближайших ДР |
| `/seed` | импорт исходных данных из `scripts/import_birthdays.py` |
| `/count` | сколько ДР в базе |
| `/dbpath` | к какой БД подключён бот |

## Запуск

Нужен Python 3.12 и PostgreSQL.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Переменные окружения:

* `BOT_TOKEN` — токен от BotFather
* `DATABASE_URL` — строка подключения к PostgreSQL

```bash
python bot.py
```

Таблицы создаются автоматически при старте. Если база пустая, бот сам
импортирует исходные данные.

---

## Добавление в группу

1. Добавь бота в группу
2. Отправь в группе любую команду, например `/month`, чтобы бот запомнил группу

---

## Скрипты

* `python -m scripts.import_birthdays` — импорт исходных данных
* `python -m scripts.list_upcoming` — ДР в ближайшие 30 дней в консоль

## Ограничения

* ДР привязан к `@username`: если человек сменит ник, ДР нужно добавить заново
* Права админа определяются по нику. Анонимные админы группы считаются обычными пользователями
