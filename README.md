# MRC Birthday Bot

Телеграм-бот напоминани1 о др

---

## Возможности

* Хранит дни рождения по `@username`
* Можно добавить в любой чат
* Напоминания:
  * за 7 дней
  * за 1 день
  * в день рождения

* За 7 дней спрашивает подарок у именинника в личке
* После выбора подарка выбор публикуется в чат

> Личные сообщения отправляются только тем пользователям, которые ранее писали боту (стартовали диалог).

## Использование в чате

### Добавление бота

1. Добавь бота в чат
2. Задать ему др
3. Чат сохранится автоматически

---

### Добавление дня рождения

```
/add @username DD.MM
```

Пример:

```
/add @alisandrii 31.10
```

---

## Проверка

### Напоминания

* Поставь дату:
  * сегодня
  * завтра
  * через 7 дней
* В 10:00 бот пришлёт сообщение

---

### Подарки

1. Именинник получает сообщение с кнопками
2. Выбирает подарок
3. Кнопки исчезают
4. В чат приходит сообщение:

```
@username выбрал подарок: Деньги
```

## Ограничения

* Требуется `@username`
* Без username бот не может писать про выбор подарка
* Бот не управляет участниками чата, если он не админ

## Траблшутинг

### 1 Имениннику не приходит ЛС с выбором подарка
- Пользователь ещё **не писал боту**. Боты не могут инициировать чат с юзером без первого сообщения.
- В текущей версии отправка в личку идёт по `@username`. Это не всегда гарантировано
- Быстрая проверка: попросите именинника нажать «Start» у бота и написать любое сообщение.

### 2 Напоминания в чаты не приходят в 10:00
- Проверьте часовой пояс планировщика: используется `Tbilisi`. Если сервер в другом TZ, время может «плавать».
- Убедитесь, что запущен **только один** процесс бота (двойной запуск мешает Scheduler).
- Проверьте, что бот не кикнут из чата и имеет право отправлять сообщения.
- Разовая ручная проверка:

# внутри Python REPL
  ```python
  import asyncio
  from bot import send_reminders, bot
  asyncio.run(send_reminders(bot))
